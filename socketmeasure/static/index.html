      关于

      SocketMeasure 通过透明 TCP 端口转发测量 socket 收发流量，会话详情支持多种解析模式 （Raw / ASCII / UTF-8 / JSON / HTTP 报文 / URL 表单 / Base64 / Hex 文本 / WebSocket 帧， 浏览器端尝试解析，失败弹窗并回退 Raw），并可热注册自定义解读器。 识别为 WebSocket 的会话可按「报文」逐条查看（RFC 6455 帧装配，与 TCP 分段无关）。 面板默认只监听 127.0.0.1，无鉴权，请勿暴露到公网。 捕获上限、保留会话数等参数见 --help。
